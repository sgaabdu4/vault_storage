# UI library

One section for each UI library glob; one row for each shared part and its purpose.

## `example/lib/core/widgets/**`

- `AppDialog` — Show an alert dialog (standard or adaptive) with title, content, and actions.
- `AppDropdownField` — Select one value from a labeled dropdown list.
- `AppElevatedButton` — Trigger a primary demo action.
- `AppTextButton` — Trigger a dialog or secondary text action.
- `AppTextField` — Collect labeled text input inside dialogs.
